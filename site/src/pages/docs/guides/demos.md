reference architecture explores. [Run the lab](/docs/guides/run-the-lab/) first.

|---|---|
| [Alice to Bob](/docs/guides/demo-alice-to-bob/) | An agent framework nobody modified, governed by her policy anyway. |

| [Two owners, two authorities](/docs/guides/demo-two-authorities/) | One agent asking two owners, who answer differently. |

| [The firm's book](/docs/guides/demo-the-firms-book/) | A resource that is hers to administer only while she is a member. |
